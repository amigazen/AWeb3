Embedded Content (HTML 4.0)

Fully Supported

  • OBJECT element - Fully supported in strict mode (see html-ks.html#OBJECT)
  • PARAM element - Fully supported (see html-ks.html#PARAM)

Partially Supported (Tolerant Mode Only)

  • EMBED element - Tolerant mode only (Netscape extension, see html-ej.html#EMBED)
  • BGSOUND element - Tolerant mode only (Internet Explorer extension, see html-ad.html#BGSOUND)

Not Supported

  • APPLET element - Not documented (deprecated in HTML 4.0, use OBJECT instead)
