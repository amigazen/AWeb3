URL Schemes: data: and cid: (Multipart MIME)

Fully Supported

  • data: URL scheme - Fully supported for embedding data directly in HTML attributes (see RFC 2397)
  • cid: URL scheme - Fully supported for referencing content by Content-ID in multipart MIME messages (see RFC 2111)
  • Base64 encoding in data: URLs - Fully supported
  • URL-encoded data in data: URLs - Fully supported

Notes

  • data: URLs are useful for embedding small resources directly in HTML, reducing HTTP requests
  • cid: URLs are essential for HTML email where resources are embedded as MIME parts
  • Base64 encoding is required for binary data in data: URLs
  • URL encoding can be used for text data in data: URLs
  • Both schemes follow RFC standards: data: (RFC 2397), cid: (RFC 2111)
  • Content-ID values in cid: URLs should match the Content-ID header in the corresponding MIME part (without angle brackets)
