Marquee Element (Netscape Extension)

Overview

The MARQUEE element is a Netscape/Internet Explorer extension that creates scrolling text or content. While not part of the HTML 4.0 standard, AWeb supports it for compatibility with legacy web pages.

Fully Supported

  • MARQUEE element - Fully supported in tolerant mode (Netscape extension)
  • Direction attribute: left, right, up, down - All supported
  • Behavior attribute: scroll, slide, alternate - All supported
  • ScrollAmount attribute - Controls pixels per scroll (default: 6)
  • ScrollDelay attribute - Controls milliseconds between scrolls (default: 85)
  • Loop attribute - Number of loops (-1 or 0 for infinite)
  • Width and Height attributes - Viewport dimensions (pixels or percentage)
  • Overflow clipping - Content is clipped to viewport bounds

Notes

  • Marquee is a non-standard element (Netscape/IE extension) and is not part of HTML 4.0
  • Marquee only works in tolerant mode (not in strict HTML mode)
  • Default direction is "left" if not specified
  • Default behavior is "scroll" (continuous) if not specified
  • Default scroll amount is 6 pixels
  • Default scroll delay is 85 milliseconds
  • Loop value of -1 or 0 means infinite scrolling
  • Content is clipped to the viewport dimensions (overflow: hidden)
  • Marquee can contain any HTML content, including links, images, and formatted text
