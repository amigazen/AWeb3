Advanced Forms (HTML 4.0)

Fully Supported

  • FORM with METHOD, ACTION, TARGET, ENCTYPE attributes - Fully supported (see html-ej.html#FORM)
  • INPUT types: text, password, hidden, checkbox, radio, submit, reset, button, file - All supported (see html-ej.html#INPUT)
  • SELECT with NAME, MULTIPLE, SIZE attributes - Fully supported (see html-ks.html#SELECT)
  • OPTION with VALUE, SELECTED attributes - Fully supported (see html-ks.html#OPTION)
  • TEXTAREA with NAME, ROWS, COLS attributes - Fully supported (see html-tz.html#TEXTAREA)
  • BUTTON element with TYPE attribute - Fully supported in strict mode (see html-ad.html#BUTTON)
