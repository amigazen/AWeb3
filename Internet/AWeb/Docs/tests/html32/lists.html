Lists

Fully Supported - Unordered Lists

What you should see: Unordered lists with different bullet styles - disc, circle, and square.

Test:
  • First unordered item
  • Second unordered item
  • Third unordered item
  • Disc bullet (default)
  • Circle bullet
  • Square bullet

Fully Supported - Ordered Lists

What you should see: Ordered lists with different numbering styles - numbers, letters, and Roman numerals, with custom start values.

Test:
  1. First ordered item
  2. Second ordered item
  3. Third ordered item
  1. Type 1 (numbers, default)
  2. Continuing with numbers
  1. Type A (uppercase letters)
  2. Continuing with letters
  1. Type a (lowercase letters)
  2. Continuing with letters
  1. Type I (uppercase Roman numerals)
  2. Continuing with Roman numerals
  1. Type i (lowercase Roman numerals)
  2. Continuing with Roman numerals
  1. Ordered list starting at 5
  2. Continuing from 5

Fully Supported - Definition Lists

What you should see: Definition lists with terms and their definitions. Multiple definitions can be associated with a single term.

Test:
Term 1
Definition 1 - can be multiple paragraphs
Term 2
Definition 2
Multiple definitions for same term

Fully Supported - Directory and Menu Lists

What you should see: Directory and menu lists, which are similar to unordered lists but with different semantic meaning.

Test:
  • Directory item 1
  • Directory item 2
  • Directory item 3
    •
  • Menu item 1
  • Menu item 2
  • Menu item 3

    Test:
