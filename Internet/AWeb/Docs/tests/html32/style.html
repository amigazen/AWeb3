Text Style Elements

Fully Supported - Physical Styles

What you should see: Text with bold, italic, underline, and strikethrough formatting.

Test:

Bold text (B) Italic text (I) Underlined text (U) Strikethrough text (STRIKE)

Fully Supported - Inserted and Deleted Text (HTML 4.0)

What you should see: Inserted text should appear in red with underline, and deleted text should appear in grey with strikethrough.

Test:

Inserted text (INS) - This text should appear in red with underline to indicate it was inserted

Deleted text (DEL) - This text should appear in grey with strikethrough to indicate it was deleted

This is normal text. This part was inserted and this part was deleted from the document.

Fully Supported - Monospace Styles

What you should see: Text rendered in monospace font for code, sample, keyboard, and variable text.

Test:

Teletype text (TT) Code text (CODE) Sample text (SAMP) Keyboard text (KBD) Variable text (VAR)

Fully Supported - Logical Styles

What you should see: Text with logical styling - emphasized, strong, citation, and definition formatting.

Test:

Emphasized text (EM) Strong text (STRONG) Citation text (CITE) Definition text (DFN)

Fully Supported - Size and Positioning

What you should see: Text with different sizes (BIG, SMALL) and positioning (subscript, superscript).

Test:

Big text (BIG) normal text small text (SMALL)

Normal text subscript (SUB) and superscript (SUP)

Fully Supported - Font Styling

What you should see: Text with different font sizes, colors, and font faces.

Test:

Font size 1 Font size 2 Font size 3 Font size 4 Font size 5 Font size 6 Font size 7

Red text Blue text Green text Magenta text (#ff00ff)

Courier font Times font

Partially Supported (Tolerant Mode Only)

What you should see: Blinking text. Note: Requires tolerant mode (Netscape extension).

Test:

This text blinks (BLINK tag - requires tolerant mode, Netscape extension)
